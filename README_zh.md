# Disc Jockey

**[English](README.md)**

在 Minecraft 中播放 [Note Block Studio](https://opennbs.org/) 歌曲——本模组会自动调好附近音符盒的音高，并按歌曲节奏模拟点击播放。

> [SemmieDev/Disc-Jockey](https://github.com/SemmieDev/Disc-Jockey) 的维护分支，适配最新 Minecraft 版本并加入一些新功能。

## 功能

### 播放核心
- 播放 `.nbs` 歌曲（生存/冒险模式可用）
- 导入 MIDI 文件（`.mid` / `.midi`）——实验性功能，需在配置中开启
- **试听**：本地预览歌曲，无需音符盒
- 可调节播放速度（`/discjockey speed`）
- 播放模式：单曲循环、列表循环、随机、播完停止

### 曲库管理
- 多级文件夹浏览（进入文件夹 / `..` 返回上级）
- 搜索（在当前文件夹内生效）
- 收藏——点击星标收藏，收藏的歌曲排在前面
- 直接把歌曲文件拖入窗口导入
- 自动滚动到上次所选歌曲，可选重启后记忆

### 智能播放
- **自动切换音符盒**——在大型音符盒阵列旁走动时，模组会重新扫描周围可用的音符盒并自动切换（可关闭）
- **实时调音校验**——播放中如果某个音符盒音高被改动（比如其他玩家重新调了音），播放会自动暂停并重新调音
- 距离判定基于原版交互范围（`blockInteractionRange`），手长类模组的加长范围同样生效
- 播放时在 HUD 上显示进度条（可关闭，打开聊天栏时自动隐藏）
- 全向音符盒音效（客户端生效，大型音符盒阵列听感更好）

### 界面交互
- 选歌界面（默认按键值为 `J` 或输入 `/discjockey` 打开）——按键绑定在按键设置中独立的"Disc Jockey"分类下
- 列表键盘导航：
  | 按键 | 功能 |
  |------|------|
  | `↑` / `↓` | 选择上/下一个条目 |
  | `Enter` | 播放选中歌曲 / 进入文件夹 / 返回上级 |
  | `Shift+Enter` | 试听选中歌曲 |
  | `←` | 焦点移出列表（到按钮） |
- 进入文件夹后自动聚焦 `..` 条目，可继续用键盘浏览和导航
- "方块"界面列出歌曲所需的全部音符盒及数量
- 乐器映射（把某个乐器映射为由其他乐器的音符盒演奏）

## 命令（`/discjockey`）

| 命令 | 说明 |
|------|------|
| `/discjockey` | 打开选歌界面 |
| `/discjockey reload` | 重新加载歌曲文件夹 |
| `/discjockey play <song>` | 按名称播放歌曲（支持 Tab 补全） |
| `/discjockey random` | 随机播放当前文件夹中的歌曲 |
| `/discjockey stop` | 停止播放 |
| `/discjockey speed <speed>` | 调节播放速度 |
| `/discjockey info` | 查看当前播放状态 |
| `/discjockey loop <yes\|no>` | 循环播放当前歌曲 |
| `/discjockey remapInstruments map\|unmap\|show\|clear` | 管理乐器映射 |

## 安装

1. 为你的 Minecraft 版本安装 [Fabric Loader](https://fabricmc.net/use/)
2. 把本模组 jar、[Fabric API](https://modrinth.com/mod/fabric-api) 和 [Cloth Config](https://modrinth.com/mod/cloth-config) 放进 `mods` 文件夹
3. 把歌曲放进 `<Minecraft 配置目录>/disc_jockey/songs/`（支持 `.nbs`、`.mid`/`.midi`）
4. 游戏内站在与歌曲乐器对应的音符盒附近，按 `J` 打开界面

> 配置文件位于 `config/disc_jockey/config.json`。

## 配置项

| 选项 | 默认值 | 说明 |
|------|--------|------|
| 隐藏警告 | 关 | 跳过反作弊警告消息 |
| 禁用异步播放 | 关 | 在客户端 tick 中同步播放音符（修复无法播放的问题，可能占用帧率） |
| 全向音符盒音效 | 开 | 仅客户端生效，见上文 |
| 服务器版本 | All | 决定音符盒可达性的判定方式（`≤1.20.4`、`≥1.20.5` 或 `All`） |
| 调音速度 | Spigot | 调音速率：Snail（10 次/秒）、Safe（20 次/秒）、Spigot、Flash——反作弊服务器请用更慢的档位 |
| 播发包速率限制 | 500/秒 | 播放时每秒交互包上限 |
| 播放延迟 | 0 秒 | 调音完成后再等待指定秒数才开始播放 |
| 乐器检测兼容 | 开 | 修复音符盒乐器识别错误；可能破坏自定义方块插件（Nexo 等） |
| 启用实验性 MIDI | 关 | 加载 `.mid`/`.midi` 文件（重新加载后生效） |
| 自动滚动到上次所选 | 开 | 打开界面时自动滚动并进入上次所选歌曲所在的文件夹 |
| 重启记忆上次选择 | 关 | 重启游戏后保留上次所选歌曲 |
| 显示进度条覆盖层 | 开 | 播放时在 HUD 显示进度条（打开界面或聊天栏时隐藏） |
| 自动切换音符盒 | 开 | 播放中离音符盒太远时，切换到其他可达的音符盒而不是停止 |
| 替换音符盒时调音 | 开 | 播放中校验目标音符盒音高，被替换或改动时自动暂停并重新调音 |

## 已知行为

- 搜索和随机播放只在当前打开的文件夹内生效
- 打开聊天栏时进度条不会显示
- 歌曲必须在生存模式下播放，创造模式会被拒绝
- 文件夹中的歌曲需要其所需乐器对应的音符盒都在交互范围内

## 常见问题

- **"你走得太远了"**——离开了某个所需音符盒的交互范围。走回去，或让"自动切换音符盒"找到其他可用方块
- **"你附近的音符盒配置不正确"**——按聊天栏列出的缺失方块补建音符盒
- **调音失败 / 被服务器踢出**——调低"调音速度"（Safe 或 Snail）和/或"播发包速率限制"
- **MIDI 文件不显示**——开启"启用实验性 MIDI"后执行 `/discjockey reload`
